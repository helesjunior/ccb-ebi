# FL-04 — Escala

**Status:** proposto · **Requisitos:** [RF-07](../funcionais/RF-07-escalas.md)

1. A coordenadora cria a escala para sessões futuras.
2. O sistema detecta conflitos e notifica a equipe.
3. A equipe confirma ou pede troca.
4. A coordenadora aprova a substituição.
5. Depois da sessão, registra-se a equipe que esteve presente.
