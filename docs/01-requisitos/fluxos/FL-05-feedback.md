# FL-05 — Feedback

**Status:** proposto · **Requisitos:** [RF-09](../funcionais/RF-09-feedback.md)

1. A operadora autorizada abre a sessão concluída e seleciona um participante presente.
2. Registra uma observação objetiva, breve e adequada à finalidade.
3. Conforme a regra de moderação ([D-05](../../06-arquitetura/decisoes/README.md)), o feedback é liberado ao responsável.
4. Alterações e contestações ficam auditadas.
