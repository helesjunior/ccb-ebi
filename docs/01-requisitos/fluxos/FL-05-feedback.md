# FL-05 — Feedback

**Status:** proposto · **Requisitos:** [RF-09](../funcionais/RF-09-feedback.md)

1. A operadora autorizada abre a sessão concluída e seleciona um participante presente.
2. Registra uma observação objetiva, breve e adequada à finalidade.
3. O irmão do **Ministério Local** da igreja modera o feedback ([ADR-0008](../../06-arquitetura/decisoes/ADR-0008-moderacao-de-feedback.md)): libera ou devolve para correção.
4. Só o feedback liberado aparece para o responsável.
5. Alterações e contestações ficam auditadas.
