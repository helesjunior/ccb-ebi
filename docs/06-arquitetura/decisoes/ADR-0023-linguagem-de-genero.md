# ADR-0023 — Linguagem de gênero nos perfis

**Status:** aceito · **Data:** 09/11/2026 · **Aprovado por:** Heles Júnior · **Resolve:** D-18

## Contexto
Os perfis "Coordenadora" e "Auxiliar" vinham no feminino. A função pode ser exercida por irmãs e, eventualmente, por irmãos.

## Decisão
- O papel é guardado **sem gênero** (por exemplo, `coordenadora` continua como código técnico, sem valor de gênero).
- Ao se referir a uma pessoa, a tela mostra "Coordenadora" ou "Coordenador" conforme o cadastro dela.
- Menus, títulos e textos genéricos usam "Coordenação" e "Auxiliar".

## Consequências
- O cadastro de usuário de equipe passa a ter a forma de tratamento (feminino/masculino).
- Os documentos continuam usando "coordenadora" como nome do papel, por consistência com o código e as versões anteriores.
