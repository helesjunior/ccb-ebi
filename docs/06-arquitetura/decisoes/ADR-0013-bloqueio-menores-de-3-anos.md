# ADR-0013 — Menores de 3 anos não participam

**Status:** aceito · **Data:** 08/11/2026 · **Aprovado por:** Heles Júnior · **Resolve:** D-14

## Decisão
Menores de 3 anos **não podem participar**. O sistema **bloqueia** o registro de presença. A exceção inclusiva não se aplica abaixo de 3 anos.

## Consequências
- RN-13 e o fluxo de elegibilidade ganharam o bloqueio explícito; novo critério de aceite CA-19.
- Cadastro antecipado de menores de 3 anos é permitido; só a presença é bloqueada ([ADR-0026](ADR-0026-confirmacoes-do-bloco-de-idade.md)).
