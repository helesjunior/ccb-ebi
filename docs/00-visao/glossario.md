# Glossário

Termos em ordem alfabética. Use estes termos em telas, documentos e código.

| Termo | Definição |
|---|---|
| ABAC | Controle de acesso por atributos e contexto (escopo territorial, vínculo ativo, finalidade, propriedade do recurso). |
| ADR | Architecture Decision Record. Registro de uma decisão com contexto, opções e consequências. |
| Auxiliar | Membro da equipe do EBI que apoia a coordenadora; pode registrar presença e contribuir com atividades conforme autorização. |
| CCB | Congregação Cristã no Brasil. |
| Central Nacional | Nível mais alto da hierarquia organizacional. |
| Coordenadora | Responsável pela condução do EBI em uma igreja; planeja sessões, escalas e feedbacks. |
| Criança | Participante dentro da faixa etária regular (3 a 11 anos). Usado só quando a regra depende de idade. |
| EBI | Espaço Bíblico Infantil. |
| Encarregado (DPO) | Pessoa indicada pelo controlador para atuar como canal com titulares e com a ANPD (LGPD, art. 41). |
| Escala | Designação de coordenadoras e auxiliares para uma sessão, com função e situação. |
| Exceção inclusiva | Autorização para participante com deficiência e/ou neurodivergência continuar no EBI fora da faixa etária regular. Ver [elegibilidade etária](../02-regras-de-negocio/elegibilidade-etaria.md). |
| Igreja de referência | Vínculo cadastral preferencial do participante. Não limita visitas a outros EBIs. |
| LGPD | Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018). |
| Matrícula | Identificador nacional único e imutável do participante. Não é segredo de acesso. |
| MFA | Autenticação multifator. |
| Participante | Pessoa atendida pelo EBI, de qualquer idade. Termo padrão do sistema. |
| Presença | Registro de que um participante esteve em uma sessão. |
| RBAC | Controle de acesso por papéis. |
| Regional | Nível da hierarquia abaixo da Central Nacional; agrupa setores. |
| Responsável | Adulto com vínculo legitimado a um participante. Pode ser pai, mãe, tutor ou outro, conforme a relação registrada. |
| RIPD | Relatório de Impacto à Proteção de Dados Pessoais. |
| RPO / RTO | Perda máxima de dados aceitável / tempo máximo de recuperação. |
| Sessão | Realização específica do EBI em data, horário e igreja definidos. |
| Setor | Nível da hierarquia abaixo da Regional; agrupa igrejas. |
| TOTP | Código temporário gerado por aplicativo autenticador. |
| Utilização | Registro confirmado de uma versão de atividade PDF em uma sessão realizada. Visualizar ou baixar não conta. |
| Vínculo | Relação com vigência entre usuário e unidade (acesso) ou entre responsável e participante (dependência). |
